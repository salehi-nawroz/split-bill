# 💸 Split Bill with friends (React)

A simple React application that helps a person to split a bill with friends and everyone needs to pay his/her portion.

This project is designed to demonstrate **core React fundamentals** using a practical, real-world example.

---
# Live Demo
[Demo of Split the Bill ](https://salehi-nawroz.github.io/split-bill)

## 🚀 Features

- List all your friends
- Be Able to select a friend
- Create a new friend
- Select a friend and split the bill

---

## 🛠️ Tech Stack

- **React**
- **JavaScript (ES6+)**
- **JSX**
- **CSS**

---

## 📚 React Concepts Used

This project showcases fundamental React concepts, including:

- Component-based architecture
- Props
- State management using `useState` hook
- Parent–child communication
- Lifting State up
- Conditional rendering
- Handling user events
